# CodSoft_Task1
Titanic Servival Rate Prediction Dashboard.

## Overview
This Power BI dashboard provides an interactive and visually appealing analysis of the Titanic dataset, helping users explore insights and patterns related to passenger survival. The dashboard also integrates a predictive model that estimates the likelihood of a passenger surviving based on key attributes such as age, gender, class, and fare.

## Dataset
The dataset used in this project contains information about passengers aboard the Titanic, including:
- **Passenger ID**: Unique identifier for each passenger.
- **Survived**: Indicates whether the passenger survived (1) or not (0).
- **Pclass**: Passenger class (1st, 2nd, or 3rd).
- **Name**: Passenger's full name.
- **Sex**: Gender of the passenger.
- **Age**: Age of the passenger.
- **SibSp**: Number of siblings/spouses aboard the Titanic.
- **Parch**: Number of parents/children aboard the Titanic.
- **Ticket**: Ticket number.
- **Fare**: Price paid for the ticket.
- **Cabin**: Cabin number (if available).
- **Embarked**: Port of embarkation (C = Cherbourg, Q = Queenstown, S = Southampton).

## Dashboard Features
- **Survival Rate Analysis**: Breakdown of survival rates based on different features (gender, class, age groups, etc.).
- **Demographic Insights**: Visual representation of the age and gender distribution of passengers.
- **Class-wise Survival Trends**: Analysis of how survival chances varied across different passenger classes.
- **Fare & Survival Correlation**: Exploration of the impact of ticket fare on survival rates.
- **Embarkation Port Analysis**: Survival trends based on embarkation location.
- **Predictive Model Integration**: The dashboard includes predictions based on machine learning models trained on the Titanic dataset.

## Usage
1. **Exploring Visuals**: Users can interact with filters and slicers to analyze survival trends based on selected attributes.
2. **Understanding Passenger Profiles**: Hover over charts and visuals to get detailed insights.
3. **Making Predictions**: Use the model’s output to understand how different attributes influence survival probabilities.

## Technologies Used
- **Power BI**: For creating interactive and dynamic visualizations.
- **Python (optional)**: Used for preprocessing and building the predictive model.
- **Machine Learning Models**: Classification algorithms such as Logistic Regression, Decision Trees, or Random Forests to predict survival.
